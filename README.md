# IELT Memory — 雅思阅读 538 自适应记忆工具

基于《剑桥雅思阅读考点词真经 538（机考笔试综合版）》整理的个人雅思阅读同义替换学习工具。

## 新版 538 数据结构

“538”并不是 538 个独立主词，而是 **376 个主考点词 + 162 个额外同义替换考点 = 538 个学习目标**：

| 类别 | 主考点词 | 额外同义替换考点 | 合计 | 建议掌握程度 |
| --- | ---: | ---: | ---: | --- |
| 第 1 类 | 20 | 34 | 54 | 滚瓜烂熟 |
| 第 2 类 | 100 | 71 | 171 | 熟记 10 遍以上 |
| 第 3 类 | 256 | 57 | 313 | 熟记 5 遍以上 |
| **总计** | **376** | **162** | **538** | — |

原始仓库曾把第 3 类做成 258 个主词，并把 `apply to`、`similar` 等同义替换项额外作为主词卡加入。新版适配层已经按 **20 / 100 / 256** 的主词结构纠正。

## 当前功能

- **今日学习队列**：优先安排已到期复习词，再加入每日新词。
- **错词即时重现**：答错后默认隔 3 张卡再次出现，直到重新巩固。
- **自适应间隔复习**：每个词独立维护 Difficulty、Stability、Retrievability，根据目标记忆率计算下一次复习时间。
- **四档记忆反馈**：忘了 / 困难 / 记住 / 太简单。
- **命题替换优先**：新版数据区分“命题同义替换”和“其它近义词”，练习优先考雅思阅读命题替换。
- **学习统计**：今日复习、正确率、稳定掌握、薄弱词、近 7 天学习量。
- **本地记忆**：学习状态保存在浏览器 localStorage 中。
- **旧版进度迁移**：会尝试读取原项目的 `538-progress` 并迁移已学位置与错题次数。
- **备份 / 恢复**：学习记录可导出 JSON，也可重新导入。
- **英式发音**：使用浏览器 Speech Synthesis，无需额外音频文件。

## 数据说明

`data-v2.js` 不再简单把所有近义词混为一个数组，而是增加：

- `examSynonyms`：优先用于雅思阅读命题训练的同义替换；
- `relatedSynonyms`：其它辅助近义表达；
- `aliases`：英式 / 美式拼写或旧版标记形式；
- `mapping`：用于标记当前词条的新版映射状态。

高频部分已经根据公开可核对的新版本表格拆分“同义替换 / 其它近义词”；其余词条保留原始完整命题替换集合，避免在未核实前人为删词。

## 使用

直接打开 `index.html` 即可使用。项目为纯前端，无服务器依赖。

如果部署到 GitHub Pages，同样可以直接运行；学习记录仍只存在用户自己的浏览器中，不会提交到 GitHub 仓库。
